## 0.1.0

* Initial release: Android `PackageInstaller` Session API installs (real-time
  progress, optional silent mode for Device-Owner/MDM apps), a Dart 3
  sealed-class update-lifecycle state machine, custom-header auth, SHA-256
  checksum + APK signature + TLS-pin verification (via `digit_downloader`), and
  no dependency on Google Play Store or Play Services.
